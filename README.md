# Resultatmålinger for a-kasser

Selvstændig visning af Jobindsats RM01AK: afgang til job og uddannelse efter 3 og 6 måneder.

Webadresse: https://ai-michelklos.github.io/resultatmaal-akasser/

## Opdatering
Workflowet synkroniserer dagligt data fra AI-MichelKlos/A-kasseindsigt-dashboard, hvor den officielle API-hentning fra Jobindsats kører. Dette repository har egne visningsfiler, men er afhængigt af kilde-repositoryets dataopdatering. Ingen API-nøgle kopieres.

Data og kildestatus hentes fra samme commit. Indhold og perioder valideres før skrivning. En mislykket kildestatus bevares som en advarsel i dashboardet.

## Publicering
GitHub Settings > Pages > Build and deployment:
Source: GitHub Actions. Workflowet publicerer efter hver synkronisering og kodeændring.

## Metode
Del 1 viser opgørelsesmåneder. Del 2 sammenholder samme startmåned efter 3 og 6 måneder.
Nyere startmåneder kan vælges, selv om 6-månedersresultatet endnu ikke er opgjort.
